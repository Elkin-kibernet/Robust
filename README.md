# Robust — Лаунчер для заработка 

**Robust** — это утилита для удобного управления сессиями и оптимизации клиента Roblox.

### Основные функции:
* **Мультиаккаунт (Mutex Manager):** позволяет запускать несколько окон Roblox одновременно.
* **Client Optimizer:** снижает нагрузку на ПК и оптимизирует работу клиента.
* **Anti-AFK:** предотвращает отключение от сервера за бездействие.
* **Автоматизация и контроль сессий:** отслеживание статуса игры через логи (без вмешательства в память игры — это **не чит** и не инжектор).

### Безопасность и открытый код
Мы понимаем, как важно беречь аккаунты в Roblox. Поэтому **весь исходный код программы полностью открыт** и выложен в этом репозитории (см. файлы `.cs` выше). 
* Программа не вмешивается в процесс Roblox и не является эксплойтом.
* Вы можете лично открыть любой файл (например, `RobloxAuthService.cs` или `ProcessLauncher.cs`) или скопировать код в любую нейросеть (ChatGPT / Claude), чтобы убедиться в полном отсутствии вирусов и стиллеров.
